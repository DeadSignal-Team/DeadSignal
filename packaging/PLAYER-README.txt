DEAD SIGNAL: THE SHIFTING FACILITY
Public playtest 0.1.0 - Windows x64

Open DeadSignal from your desktop or Start Menu after installing.
Java, JavaFX, the sprites, room artwork, and both videos are included.
You do not need to install Java, Git, VS Code, or use PowerShell to play.

Find the keycard and escape the shifting facility while avoiding the monster.

WASD / arrows: move             Shift: run
E: pick up an object            Q: throw the held object
F: enter / leave a locker       Space: open / close the door you face
M: remembered map               P: warning volume / reduced effects
Esc: close map / pause menu     R: restart

SKIP dismisses the intro or successful-escape outro.
CONTINUE resumes a run while this application remains open.
Run progress is not saved after closing the application.

The map hides unexplored rooms and never displays the monster.
It stays open for up to 10 seconds, with a 25-second cooldown from opening.
The monster continues moving while the map is open.
Room connections on the remembered map can become outdated after shifts.
